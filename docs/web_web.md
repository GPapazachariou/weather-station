# web/web.py Documentation

## Purpose
- Flask web dashboard providing HTML UI and JSON APIs to read weather data from the SQLite database generated by the TCP server.
- Used by the `web` Docker service; the front-end (templates/index.html, static/app.js) consumes the API endpoints defined here.

## High-level flow
- Startup: module configures logging, resolves DB path (env `WEATHER_DB_PATH`), initializes Flask app with templates/static, logs DB presence, and may detect wind column name when run as `__main__`.
- Runtime (server mode): Flask handles requests:
  - `/` renders the dashboard page.
  - `/api/stations` lists station IDs.
  - `/api/stats` returns latest/avg/min/max for a station/metric/time range.
  - `/api/readings` returns time series points for a station/metric/time range.
- Shutdown: relies on Flask/Werkzeug lifecycle; SQLite connections are short-lived per request.

## Key data structures
- Constants: `DEFAULT_DB_PATH`, `DB_PATH` (env override), `WEB_HOST`, `WEB_PORT` (env overrides), `VALID_RANGES` (6h, 24h timedeltas), `VALID_METRICS` set, `_wind_column_cache` (memoizes detected wind column).
- Shared state: module-level cache `_wind_column_cache` to avoid repeated PRAGMA queries.
- Message formats: JSON responses for stations (`{"stations": [...]}`), stats (`{"latest":..., "avg":..., ...}`), readings (`{"points": [{"t": ts, "v": value}, ...]}`), error cases return empty structures with HTTP 400 where appropriate.

## Functions
### Function: detect_wind_column()
- Signature: `def detect_wind_column()`
- Parameters: none.
- Returns: string column name (`"windspeed"` or `"wind_speed"`), fallback `"windspeed"` on failure.
- Side effects: opens and closes SQLite connection; caches result in `_wind_column_cache`; logs detection or warning.
- Errors: exceptions are caught; on error, cache set to fallback.
- Notes: Supports DBs created with different wind column naming.

### Function: normalize_metric(metric)
- Signature: `def normalize_metric(metric)`
- Parameters: `metric` string from UI/API (`"temperature"`, `"humidity"`, `"windspeed"`).
- Returns: actual DB column name, mapping wind metrics via `detect_wind_column`.
- Side effects: may trigger column detection (DB access) on first call.

### Function: get_db()
- Signature: `def get_db()`
- Parameters: none.
- Returns: SQLite connection with `row_factory=sqlite3.Row`, `timeout=5.0`, `check_same_thread=False`.
- Side effects: opens DB; caller must close.

### Function: parse_timestamp(ts)
- Signature: `def parse_timestamp(ts)`
- Parameters: `ts` string or epoch-like.
- Returns: naive `datetime` or `None` if unparsable.
- Side effects: none.
- Notes: Accepts ISO with `Z` or offset; falls back to epoch float.

### Function: index()
- Signature: `@app.route("/") def index()`
- Parameters: none.
- Returns: rendered `index.html` template.
- Side effects: template rendering.

### Function: api_stations()
- Signature: `@app.route("/api/stations", methods=["GET"])`
- Parameters: none.
- Returns: JSON `{"stations": [..]}` with ordered distinct station IDs.
- Side effects: DB read.
- Errors: on exception, logs error and returns empty list (HTTP 200).
- Notes: Defensive to keep UI functional even if DB issues occur.

### Function: api_stats()
- Signature: `@app.route("/api/stats", methods=["GET"])`
- Parameters (query): `station_id` (required), `metric` (required), `range` (required: 6h or 24h; code mentions 1h/7d in docstring but validated set is 6h/24h).
- Returns: JSON with latest, latest_t, avg, min, max (rounded) or nulls on missing data; HTTP 400 on invalid params.
- Side effects: DB read.
- Errors: wraps DB errors and returns nulls without raising.
- Notes: Filters rows in Python by timestamp cutoff; ignores null metric values; logs counts.

### Function: api_readings()
- Signature: `@app.route("/api/readings", methods=["GET"])`
- Parameters (query): `station_id`, `metric`, `range` (same validation as stats).
- Returns: JSON `{"points": [{"t": ts, "v": value}, ...]}` ordered oldest→newest; HTTP 400 on invalid params.
- Side effects: DB read.
- Errors: on exception, returns empty list.
- Notes: Filters by time window and drops nulls; uses normalized metric column; logs point count.

### Main guard
- When run directly, logs banner, DB path/existence, and detected wind column, then runs `app.run(host=WEB_HOST, port=WEB_PORT, debug=False, use_reloader=False)`.

## Error handling & edge cases
- Missing/invalid query params: return HTTP 400 with empty structures for stats/readings.
- DB missing/unreadable: stations returns empty list; stats/readings return empty/null payloads; errors are logged.
- Metric column variance: handled via detection fallback to `windspeed` to avoid crashes.
- Timestamp parse failures: rows with unparsable timestamps are skipped.

## Performance & scalability notes
- Each request opens a new SQLite connection; lightweight but could be optimized with pooling if needed.
- Filters are done in Python after selecting all rows per station; for very large datasets, this may become slower—time windows mitigate this.
- Read-only access on a shared WAL-enabled DB (set by server) keeps contention low.

## How to test this file
- Run the web app:
  ```bash
  python web/web.py
  ```
- With existing data, verify endpoints:
  ```bash
  curl "http://127.0.0.1:8000/api/stations"
  curl "http://127.0.0.1:8000/api/stats?station_id=STATION-001&metric=temperature&range=24h"
  curl "http://127.0.0.1:8000/api/readings?station_id=STATION-001&metric=humidity&range=6h"
  ```
- Open the dashboard at http://127.0.0.1:8000 and confirm station dropdown, stat cards, and chart/table render data without errors.
